# Endless Exposure

Sei secoli di pittura, sala per sala: movimenti, artisti e opere, con il quadro in primo piano e lo zoom profondo IIIF quando il museo lo offre.

Opere da Wikidata e Wikimedia Commons, più le collezioni aperte del Cleveland Museum of Art, del Metropolitan Museum of Art e dell'Art Institute of Chicago. Solo opere di pubblico dominio.

Un solo file (`index.html`), pubblicato con GitHub Pages.
